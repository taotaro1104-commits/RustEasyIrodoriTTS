### コンソール
- JavaScript の例外は 0 件。
- 操作の途中で出る「Failed to load resource」は、意図して発生させた 501（未対応ルート）・400（辞書の入力不足）・403（トークン無しの確認）の、ブラウザ自身の記録のみ。
- **見つけた問題 1 件（修正済み）**: ブラウザが自動で取りに来る `/favicon.ico` が 404 で、コンソールにエラーが残った。テスト `favicon_request_is_answered_quietly`（RED 確認済み）を先に足し、204 を返すようにして解消。修正後に新しく読み込んだページは、コンソールのメッセージが 0 件。

## 画面の仕様として確認した点（不具合ではない）
- 辞書フォームは、保存に成功すると入力欄を空にする。続けて読み方だけを送ると「「表記」と「読み方」の両方を入力してください。」になる（v2.0 と同じ）。
- 辞書の「削除」を画面から行っても通知は出ない（editor のコードがそうなっている）。
